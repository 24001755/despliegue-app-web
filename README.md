# Despliegue de Aplicación Web Móvil - Reto 2

Este repositorio contiene la preparación, optimización y versión final de una aplicación web ligera para su despliegue en servidor web.

## Estructura del Proyecto
- `/css`: Hojas de estilo optimizadas y minificadas.
- `/js`: Scripts de interacción cliente minificados.
- `/img`: Recursos multimedia comprimidos.
- `index.html`: Estructura principal de la aplicación.

## Proceso de Despliegue
1. **Empaquetado:** Estructuración de directorios y generación de archivo comprimido `.zip`.
2. **Versionamiento:** Control de cambios con Git y sincronización con GitHub.
3. **Servidor Web:** Configuración de Virtual Host / mapeo en servidor Apache (XAMPP) accesible en `http://localhost/tuapp`.
